## 性能分速查

性能分按平均推理 FPS 线性折算，参考点：

| 平均 FPS | 性能分 |
| ---: | ---: |
| 1 | 1 |
| 10 | 5 |
| 25 | 12.5 |
| 50 | 25（满分，超过不再加分） |

所以「精度换速度」的取舍要先算清：某方案 F1 高 0.02（≈ 1.5 分，按三视角加权后），如果因此把 FPS 从 30 拖到 20（≈ 少 5 分），净亏。
